# Generate Feature Map

Inspect the target application and generate a verified `FEATURE_MAP.md`.

The map must cover:

1. Architecture and feature hierarchy with source directories.
2. Navigation workflows, routes, and URLs.
3. Global and context-specific keyboard shortcuts.
4. Test IDs, DOM selectors, and automation attributes.
5. Verification hooks, expected states, network activity, traces, and logs.

Use evidence from source, tests, routes, and runtime inspection. Mark unknown
items as unverified. Do not invent selectors or navigation paths. Update the
map incrementally when the application changes.
